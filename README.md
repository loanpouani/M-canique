# ⚙️ Projet de mécanique – Fast & Furious

Projet académique réalisé à CESI dans le cadre du bloc **Mécanique**.

## 🎯 Objectif

Étudier la faisabilité d'un circuit automobile comprenant une pente, un looping et un saut de ravin, afin de déterminer quel modèle de voiture permet de réaliser le parcours dans les meilleures conditions.

L'étude consiste à modéliser le mouvement de la voiture, résoudre numériquement les équations obtenues et comparer les résultats théoriques avec des mesures expérimentales.

## 🔬 Travail réalisé

Le projet est organisé en trois parties :

- **Étude et modélisation du système** : choix des repères et référentiels, étude des forces et établissement des équations du mouvement à partir de la deuxième loi de Newton.
- **Résolution numérique** : résolution des équations différentielles à l'aide de méthodes numériques, notamment la méthode d'Euler, avec implémentation en Python.
- **Comparaison modèle / réalité** : analyse des mesures expérimentales, calcul des incertitudes et comparaison avec les résultats théoriques.

## 🛠️ Technologies et méthodes

- Python
- Méthode d'Euler
- Modélisation mathématique
- Lois de Newton
- Résolution d'équations différentielles
- Analyse d'incertitudes
- Markdown / LaTeX

Le repository contient le code Python, les documents de travail et les résultats associés à l'étude.
